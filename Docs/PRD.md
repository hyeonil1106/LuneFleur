# PRD.md

# 제품 요구사항 정의서 (PRD) : 탄생화 향수 브랜드 'Fleur de Mot' 홍보 랜딩 페이지

## 1. 프로젝트 개요 (Overview)
*   **프로젝트명:** 플레르 드 모 (Fleur de Mot) 홍보 랜딩 페이지 개발
*   **핵심 타겟:** 23세 ~ 32세 여성 (Main 페르소나: 26세 김서연, 브랜드 마케터)
*   **브랜드 감성:** 나만을 위해 준비된 특별한 선물을 받는 듯한 설렘, 나만의 리추얼(Ritual)
*   **기술 스택:** React + Vite + Vanilla CSS (컴포넌트 스코핑 및 순수 인터랙션 구현 중심)

---

## 2. 디자인 시스템 기본 정의 (Design System)
*   **컬러 팔레트 (새벽의 정원):**
    *   배경색 (Background): `#F9F8F6` (소프트 아이보리)
    *   주조색 (Main Text/UI): `#4A5846` (세이지 그린)
    *   강조색 (Accent/CTA): `#C29B74` (뮤티드 골드)
*   **타이포그래피:**
    *   헤드라인/강조용: 영문 `Cormorant Garamond` (Serif) / 국문 명조 계열
    *   본문/실용 정보용: 영문 `Inter` (Sans-serif) / 국문 고딕 계열 (`Noto Sans KR`)

## 3. 섹션별 상세 구성 및 모션 플로우

### SECTION 01 : Hero (인트로)
*   **목적:** 브랜드 첫인상 각인 및 3초 이내 스크롤 락(Lock).
*   **레이아웃:** Full Screen (100vh), 중앙 집중형 텍스트, 하단 고정 CTA.
*   **포함 요소:** 바이페이즈 제형이 섞이는 고화질 루핑 백그라운드 영상, 메인 타이틀, 서브 타이틀, CTA 버튼.
*   **헤드라인:** `당신이 태어난 달의 문장, 하루 종일 은은하게 피어나는 향`
*   **CTA 문구:** `[ 내 탄생화 향수 확인하기 → ]`
*   **모션 플로우:**
    *   *진입 시:* 배경 영상이 부드럽게 페이드인(`opacity: 0 -> 1`)되며, 타이틀 텍스트가 중앙에서 사방으로 퍼지듯 서서히 스케일업되며 나타남(꽃이 피어나는 Blooming 이펙트).
    *   *스크롤 시:* 다음 섹션 진입 전까지 텍스트가 위로 부드럽게 패러랙스(Parallax)되며 투명도가 낮아짐.
    *   *호버 시 (CTA):* 버튼 배경색이 자연스럽게 투명해지며 테두리와 폰트에 뮤티드 골드 컬러가 스며듦.

### SECTION 02 : Interactive Intro (개인화 큐레이션)
*   **목적:** 생일 입력을 통한 몰입도 극대화 및 나만의 탄생화 발견.
*   **레이아웃:** 2컬럼 배치가 모바일에서 1컬럼으로 스택되는 형태 (좌: 문구 / 우: 생일 입력 인풋 필드).
*   **포함 요소:** 안내 카피, 월/일 셀렉트 박스(또는 커스텀 드롭다운), 확인 버튼.
*   **헤드라인:** `당신의 계절이 시작된 날, 어떤 꽃이 피어났나요?`
*   **모션 플로우:**
    *   *진입 시:* 왼쪽 카피가 먼저 슬라이드인 되고, 오른쪽 인풋 폼이 순차적으로 떠오름(Stagger 적용).
    *   *클릭 시 (확인 버튼):* 사용자가 날짜를 선택하고 클릭하면 화면 전체에 미세한 그라디언트 블러(Fluid Blur)가 일어나며 결과 레이어로 부드럽게 전환.

### SECTION 03 : Product Showcase (비주얼 증명)
*   **목적:** 프리저브드 꽃잎과 바이페이즈 제형의 독보적 시각 가치 증명.
*   **레이아웃:** 그리드 또는 가로 스크롤 레이아웃. 고화질 매크로(클로즈업) 컷 배치.
*   **포함 요소:** 바이페이즈 흔들림 전/후 비교 영상, 보틀 속 실제 프리저브드 꽃잎 디테일 이미지, 메탈 캡 각인 상세 컷.
*   **헤드라인:** `눈을 감아도, 떠도 영롱한. 보틀 속에 박제된 당신의 탄생화`
*   **모션 플로우:**
    *   *스크롤 시:* 사용자가 스크롤을 내릴 때 마우스 휠 속도에 맞춰 보틀 이미지가 미세하게 회전(Rotate)하거나 진동하여, 오일층이 흔들리는 듯한 시각적 잔상이 남도록 연출.

### SECTION 04 : Brand Story & Efficacy (감성적 실용성)
*   **목적:** 스토리텔링과 오일 베이스의 압도적인 잔향 지속성(실용성) 설득.
*   **레이아웃:** 미니멀한 좌우 반전 레이아웃 (텍스트와 감성 무드 컷의 대조).
*   **포함 요소:** 탄생화 꽃말에 얽힌 브랜드 스토리 서사 문구, 오일+워터 지속 메커니즘 그래프 또는 감성 인포그래픽.
*   **헤드라인:** `코 끝에 머무는 은은함, 아침의 설렘이 퇴근길의 잔향으로`
*   **모션 플로우:**
    *   *스크롤 시:* 스크롤 트래킹을 통해 배경의 연한 베이지/그린 컬러가 물속에서 물감이 번지듯 유기적으로 형태를 바꾸는 모핑(Fluid Morphing) 애니메이션 구현.

### SECTION 05 : Social Proof (신뢰 구축)
*   **목적:** 인플루언서 및 실구매자 리뷰를 통한 구매 전환 유도.
*   **레이아웃:** 인스타그램 피드를 옮겨온 듯한 3컬럼 카드 뷰 레이아웃.
*   **포함 요소:** 감성적인 제품 연출 샷 중심의 사용자 리뷰 이미지, 평점, 텍스트 후기.
*   **헤드라인:** `이미 많은 이들의 화장대 위에서 피어나는 중입니다`
*   **모션 플로우:**
    *   *진입 시:* 리뷰 카드가 아래에서 위로 리드미컬하게 통통 튀듯 페이드인.
    *   *호버 시:* 특정 리뷰 카드에 마우스를 올리면 카드가 살짝 위로 부드럽게 플로팅(`transform: translateY(-8px)`)되며 그림자 깊이감이 깊어짐.

### SECTION 06 : Epilogue & CTA (최종 전환)
*   **목적:** 선물 패키징 리추얼을 보여주며 최종 구매 링크로 유도.
*   **레이아웃:** 미니멀한 중앙 집중형 박스 레이아웃. 고급 기프트 패키지 컷 전면 배치.
*   **포함 요소:** 기프트 포장 비주얼, 브랜드 최종 슬로건, 최종 메인 CTA 버튼.
*   **헤드라인:** `가장 특별한 날에 태어난 당신에게, 탄생화의 문장을 선물하세요.`
*   **모션 플로우:**
    *   *진입 시:* 화면 전체의 배경색이 가장 차분하고 포근한 `시간의 잔향` 톤으로 부드럽게 전환되며 스크롤이 멈추는 느낌을 줌.
    *   *호버 시 (CTA):* 버튼 내부가 은은하게 반짝이는 듯한 그라디언트 무빙 효과 리플(Ripple) 적용.

## 4. 인터랙션 포인트 종합 목록 (Interaction Points)

1.  **마우스 커서 인터랙션 (Desktop):**
    *   일반 영역에서는 미니멀한 원형 커서 유지.
    *   SECTION 03(Showcase) 및 이미지 오브제 영역 진입 시 커서가 크게 확장되며 내부 텍스트로 `DRAG` 또는 `SHAKE`라는 가이드 문구가 표시됨.
2.  **스크롤 트리거 (Scroll Trigger):**
    *   웹사이트 전체에 `transition: transform 0.6s cubic-bezier(0.16, 1, 0.3, 1)` 속성을 기본으로 한 부드러운 관성 스크롤(Smooth Scroll) 감성 적용.
3.  **인풋 필드 포커싱 (Focus):**
    *   생일 입력 셀렉트 박스 클릭 시, 테두리가 은은하게 골드 베이지 색상으로 번지며 포커싱 처리됨.
4.  **최종 CTA 버튼 (Click):**
    *   `[ 내 탄생화 향수 확인하기 → ]` 버튼 클릭 시, 화살표(`→`) 아이콘이 오른쪽으로 튕겨 나가는 듯한 모션 후 페이지 스무스 스크롤 이동 또는 결과 팝업 노출.

## 5. 모바일 대응 방향 (Mobile Responsive Web UX)

*   **비주얼 에셋 최적화:** 모바일 환경에서 로딩 저하를 방지하기 위해 Hero 세션의 백그라운드 비디오는 대역폭에 따라 720p 최적화 고효율 `mp4/webm` 포맷으로 제공하며, 불가능할 경우 정적인 최적화 이미지로 대체 폴백(Fallback) 처리.
*   **레이아웃 다운스케일링:** 
    *   Desktop의 2컬럼, 3컬럼 레이아웃은 모바일(768px 이하) 진입 시 무조건 `flex-direction: column`으로 일렬 스택 배치.
    *   SECTION 05(리뷰)의 경우 모바일 스크롤 압박을 줄이기 위해 세로 배열 대신 좌우로 넘겨보는 **스와이프(Swipe) 터치 슬라이더(X축 스크롤)** 형태로 변경.
*   **터치 타겟 최적화:** 생일 입력 드롭다운 메뉴 및 CTA 버튼의 최소 터치 영역을 `48px * 48px` 이상으로 확보하여 모바일 오클릭 방지.
