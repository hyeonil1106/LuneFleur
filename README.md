# 🌸 LuneFleur (룬플뢰르) - AI 기반 프리미엄 향수 랜딩페이지

> "당신이 태어난 달의 문장, 하루 종일 은은하게 피어나는 향. 나만의 탄생화 향수를 만나는 여정."

## 1. 프로젝트 소개

- **설명:** 12달의 탄생화를 모티브로 한 향수 랜딩페이지입니다.
- **진행 방식:** AI 기반 에이전트(Antigravity)를 활용한 Vibe Coding (프롬프트 주도 개발)
- **개발 인원:** 개인 프로젝트 (기여도100%)

---

## 2. 사용 기술 스택

### Frontend
- **React.js & Vite:** 빠르고 반응성 높은 컴포넌트 기반 UI 구축 및 쾌적한 개발 환경 구성.
- **Vanilla CSS:** 복잡한 애니메이션, 3D CSS Flip, Fluid Typography 등 세밀한 디자인 튜닝을 위한 순수 CSS 활용.
- **WebGL / React Bits:** 화면 터치 시 물감(유체)이 번지는 화려한 시각적 효과(`SplashCursor`) 구현.

### 🤖 AI-Assisted Development (Vibe Coding)
- **Google Gemini / Antigravity:** UI 컴포넌트 리팩토링, 3D 카드 레이아웃 디버깅, 동적 효과(SplashCursor) 통합 등 페어 프로그래밍.
- **AI 이미지 생성 도구:** 프롬프트 엔지니어링을 통해 12달 탄생화의 투명한 수채화 풍 이미지 에셋 생성 및 배경 누끼 작업 자동화.

---

## 3. 사용자 여정 (User Flow)

1. **메인 인트로 (Hero):** 접속 시 유체 시뮬레이션 커서 효과와 함께 시각적 임팩트 전달
2. **브랜드 스토리 (Story):** 향수가 가진 의미와 철학 전달
3. **탄생화 찾기 (Birth Flower):** 사용자가 직접 자신의 월별 탄생화 향수를 탐색
4. **컬렉션 (Showcase):** 제품의 고급스러운 패키지와 외관을 3D 호버 효과로 감상
5. **효능 및 조향 (Efficacy):** 3D로 뒤집히는 카드를 통해 탑/미들/베이스 향기 노트 프로파일과 지속성 확인
6. **리뷰 및 선물하기 (Reviews & Gift):** 실제 사용자들의 리뷰와 최종 구매/선물 유도 (CTA)

---

## 4. AI 활용 및 개발 워크플로우

- **다국어 및 로컬라이제이션:** 영문으로 작성되어 있던 네비게이션 메뉴를 사용자 친화적인 한글 메뉴(브랜드 스토리, 탄생화, 쇼케이스, 효능, 리뷰 등)로 자연스럽게 번역 및 수정.
- **UI/UX 폴리싱 및 레이아웃 수정:**
  - `Efficacy` 섹션의 원형 갤러리 3D 카드 뒷면 텍스트가 잘리는 현상을 해결하기 위해 카드 비율 및 CSS 컨테이너 크기 비례 조정.
  - 성분표를 향수 특성에 맞게 '향기 노트 프로파일' 차트로 데이터를 전면 리팩토링.
  - `.showcase-title` 등 각 섹션별로 흩어져 있던 타이포그래피(폰트)를 Serif 계열로 통일하여 고급스러운 무드 연출.
- **동적 이펙트 통합:** 오픈소스 `SplashCursor` 컴포넌트를 `.hero` 섹션의 로딩 완료 시점에 맞춰 조건부 마운트되도록 매끄럽게 통합.
- **에셋 생성:** 11월(국화), 12월(포인세티아) 등 특정 월의 이미지를 "흰색 배경에 격리된 부드러운 수채화" 프롬프트로 재생성 후 CSS `mix-blend-mode: multiply`와 완벽히 결합.

---

## 5. 핵심 구현 기능

- **유체 시뮬레이션 인터랙션:** 마우스나 터치 이동에 따라 번지는 물감 효과(`SplashCursor`)로 브랜드의 우아하고 감성적인 아이덴티티 시각화.
- **3D 인터랙티브 갤러리:** 좌우 스와이프로 회전하는 원형 갤러리 및 호버/클릭 시 카드가 180도 뒤집히며 뒷면의 향기 노트를 보여주는 화려한 3D CSS 효과 적용.
- **반응형 웹 디자인(RWD):** PC, 태블릿, 모바일 등 어떤 기기에서도 레이아웃이 깨지지 않도록 유동적 글꼴(clamp) 및 CSS Grid/Flexbox 적극 활용.

---

## 6. 트러블 슈팅 (Troubleshooting)

### 💡 이슈 1: 이미지를 생성하는 과정에서 발생한 오류
- **상황:** 이미지를 생성하는 과정에서 코인을 다 써서 생성 하는것을 기다려양 하는 상황이 발생함
- **해결:** 제미나이나 다른 AI 사이트를 이용해서 이미지를 생성하고 그 파일을 사용

### 💡 이슈 2: 마우스 커서 효과를 구현하는 과정에서 발생한 오류
- **상황:** 마우스 커서 효과를 구현하는 과정에서 브라우저가 느려지는 현상이 발생함
- **해결:** 마우스 커서 효과를 삭제하고, 딜레이 걸리는 부분을 찾아 제거후 다시 적용
